The commands this guide runs, in chapter order.
Everything was run against the lab's own fixtures on 127.0.0.1.

Chapter 2 — installing
  gping --version                      -> gping 1.21.0
  gping --help                         (full text in gping-lab/transcripts/t14-help.txt)

Chapter 3 — your first graph (TCP mode, fixture server running)
  python3 fixtures/slow-server.py      (listens on 127.0.0.1:18091)
  gping --tcp --tcp-port 18091 127.0.0.1
  q                                    (stops gping)

Chapter 8 — the refusal trap
  gping --tcp --tcp-port 18091 --tcp-rst drop 127.0.0.1
      (server killed mid-run: line stops, t/o climbs)
  gping --tcp --tcp-port 18091 127.0.0.1
      (server down, default --tcp-rst pong: refusals pose as replies)
  python3 fixtures/deaf-server.py      (listens, never accepts)
  gping --tcp --tcp-port 18091 127.0.0.1
      (a few pongs from the queue, then silence)

Chapter 7 — graph a command
  gping --cmd fixtures/steady.sh       (sleeps 0.12 every time)
  gping --cmd fixtures/jitter.sh       (sleeps 0.04-0.29, at random)
  gping --cmd -c cyan,magenta fixtures/fast-fetch.sh fixtures/slow-fetch.sh
  gping --cmd false                    (always fails: timeouts only)

Chapter 6 — display options
  gping --cmd --buffer 10 fixtures/steady.sh
  gping --cmd --ymin 0 --ymax 200 fixtures/steady.sh
  gping --cmd --simple-graphics fixtures/jitter.sh

Chapter 9 — the permission question
  cat /proc/sys/net/ipv4/ping_group_range     -> 65534 65534
  ping -c 2 -W 1 127.0.0.1                    -> socket: Operation not permitted
  gping 127.0.0.1                             -> gping shows ping's error and exits
